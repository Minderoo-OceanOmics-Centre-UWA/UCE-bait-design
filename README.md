# UCE-bait-design

This repository contains the code to generate the Actinopteri ultra conserved element baitset designed for OceanOmics eDNA. 
20 reference genomes across the orders of Actinopteri were used to identify UCEs and design probes to target them. 

Bait design follows along with the phyluce Tutorial IV: Identifying UCE Loci and Designing Baits To Target Them with a few modifications.

The bait-design.sh contains all code, settings and tool versions used to generate the baits, as well as the NCBI accession numbers for the genomes.
